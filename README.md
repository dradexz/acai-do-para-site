# Açaí do Pará

Site acadêmico de gastronomia paraense. HTML, CSS e JavaScript, com fotografias locais, catálogo, filtros, carrinho demonstrativo, validação de contato e montador de combinação.

## Publicação

GitHub Pages via GitHub Actions: o workflow extrai `site-publicacao.zip` e publica seu conteúdo. A branch de trabalho é `main`. O arquivo `.nojekyll` mantém a publicação estática sem processamento Jekyll.

## Limites

O carrinho é salvo neste navegador. O formulário valida os dados e não envia mensagens. Não há pagamento nem pedidos reais. PHP e MySQL não fazem parte desta versão estática do GitHub Pages.

## Créditos

Veja `paginas/creditos.html` para autoria e condições de uso das fotografias. As imagens de terceiros mantêm seus direitos e licenças; este repositório não concede uma licença geral sobre elas.
